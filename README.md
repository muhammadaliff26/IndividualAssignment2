**Brief Project Description:**

The Student Profile Management System is a dynamic web application built using Java EE (JSP & Servlets) and Apache Derby. It provides a seamless platform for users to submit, view, search, and filter student profiles. Designed with a modern, responsive UI featuring a dark-themed glassmorphism aesthetic, the application demonstrates robust server-side processing, database integration via JDBC, and user-friendly interface design.

**List of Implemented Features:**

Profile Submission Form: Allows users to input detailed student information, including Full Name, Student ID, Programme, Email, Hobbies, and a brief Introduction.

Database Integration: Seamlessly connects to an Apache Derby database using JDBC to safely store, retrieve, and manage all student records.

View All Profiles: Dynamically fetches and displays a comprehensive list of all registered student profiles in an organized layout.

Advanced Search Engine: Users can pinpoint specific profiles by searching directly for a "Student ID" or "Name".

Dynamic Filtering System: Automatically generates dropdown lists based on existing database entries, allowing users to filter profiles by "Programme" or "Hobby".

Modern & Responsive UI: Built with custom CSS, utilizing Flexbox/Grid layouts, FontAwesome icons, and Google Fonts (Poppins) to ensure the application looks pristine on both desktop and mobile devices.

Success & Error Handling: Provides clear, visual feedback to the user after form submissions or invalid search queries.
