About This System

This application has been upgraded from a simple profile viewer into a fully dynamic Profile Management System following the MVC software design pattern.

Enterprise Architecture Stack

Model: JavaBean View: JSP & HTML5 Controller: Servlet Database: Apache Derby Bridge: JDBC Server: GlassFish

Key Features

  • Persistent data storage using relational database
  • Search profiles by Student ID and Name
  • Filter profiles by Programme and Hobbies
  • Responsive glassmorphic UI design

Learning Outcomes

  • Decoupling backend controllers from frontend layers
  • Managing dynamic SQL using JDBC Prepared Statement
  • Implementing MVC architecture pattern
